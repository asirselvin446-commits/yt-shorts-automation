Privacy Policy

Last updated: 14 October 2026

YT Shorts Automation is a personal tool run on the owner's own computer. It is used only by the owner of the YouTube channel it is connected to.

Data accessed

With the owner's consent through Google OAuth, the tool uses the YouTube Data API and YouTube Analytics API to upload videos, set video metadata and schedules, and read view and watch-time statistics for the owner's own channel.

Storage

OAuth tokens and statistics are stored only on the owner's computer. No data is sold, shared with third parties, or sent to any server operated by this tool.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
